# Key bindings

`?` shows these in the app. Counts work with movement: `5j`.

## Navigation

| Keys | Action |
|---|---|
| `j` `k` (or `↓` `↑`) | down, up |
| `h` (or `←`, `Backspace`) | parent folder |
| `l` (or `→`, `Enter`) | open |
| `gg` `G` | first, last entry |
| `Ctrl-d` `Ctrl-u` | half page down, up |
| `-` | previous folder |
| `Tab` `Shift-Tab` | move between the accounts list and the panes |
| `Ctrl-n` `Ctrl-p` | next, previous account, from the pane (Files and Space) |
| `\|` | open or close a second pane |
| `/` then `n` `N` | filter the folder, next and previous match |
| `sn` `ss` `sm` | sort by name, size, modified |
| `sr` | reverse the sort |
| `.` | show or hide hidden files |
| `R` | refresh the folder and its account's usage |
| `i` | show or hide the info panel |

## Files

| Keys | Action |
|---|---|
| `Space` | mark |
| `v` `V` | visual selection |
| `Esc` | clear the selection |
| `y` | copy |
| `x` | cut |
| `p` | paste here |
| `>` or `F5` | copy to the other pane |
| `F6` | move to the other pane |
| `r` or `cw` | rename |
| `o` or `a` | new folder |
| `dd` or `D` | delete (asks first) |

## Tabs

| Keys | Action |
|---|---|
| `gt` `gT` | next, previous tab |
| `Alt-1` `Alt-2` `Alt-3` | Files, Space, Transfers |
| `U` | Space |
| `T` | Transfers |

## Accounts list

| Keys | Action |
|---|---|
| `l` or `Enter` | open the account |
| `a` | add an account |
| `e` | edit the account |
| `A` | sign in again |
| `dd` or `D` | remove the account |
| `r` or `R` | refresh its usage |

## Transfers tab

| Keys | Action |
|---|---|
| `s` or `x` | stop |
| `Enter` or `r` | resume |
| `c` | clear finished |
| `dd` or `D` | remove from the list |
| `C` | clear all but running |
| `T`, `q` or `Esc` | close |

## Space tab

| Keys | Action |
|---|---|
| `Enter` | open the folder, or start the scan |
| `l` `h` (or `-`) | into a folder, back out |
| `ss` `sn` `sc` | sort by size, name, file count |
| `/` | filter |
| `gf` | open the folder in Files |
| `R` | scan again |
| `Esc` | cancel the scan, or go back |
| `q` | back to the files |

## Everywhere

| Keys | Action |
|---|---|
| `,` | settings |
| `?` | help |
| `q` or `Ctrl-c` | quit (asks what to do with running transfers) |
